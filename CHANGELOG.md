# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/)
and this project adheres to [Semantic Versioning](http://semver.org/).

## [Unreleased]

## [0.2.5] - 2026-07-27
### Fixed
- Add `repository` information to `package.json`

## [0.2.4] - 2026-07-27
### Fixed
- Fix schema for `step.before` and `step.after` in `cucumber-jvm.json`

## [0.2.3] - 2025-09-09
### Fixed
- Add missing `JvmStatus.ambiguous`

## [0.2.2] - 2025-09-03
### Fixed
- `JvmArgument.val` and `JvmArgument.offset` are not required

## [0.2.1] - 2025-07-22
### Fixed
- Added missing `step.before` and `step.after` to `cucumber-jvm.json`

## [0.2.0] - 2025-07-22
### Changed
- Sort keys for clarity

### Fixed
- Added missing `step.embeddings` and `step.output` to `cucumber-jvm.json`

## [0.1.1] - 2024-04-21
### Changed
- Add tests and workflows ([#7](https://github.com/cucumber/cucumber-json-schema/pull/7))

## [0.1.0] - 2024-04-18
### Added
- Initial release
